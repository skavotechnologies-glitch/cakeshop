# Maison de Cake — Luxury Artisan Patisserie

> **Crafted with Love. Baked to Remember.**

A **premium, highly animated, luxury dessert boutique landing page** inspired by Parisian pastry ateliers, modern editorial food photography, and minimalist fashion design.

---

## 🎂 Features

- **Cinematic Hero:** Staggered headline reveal, floating strawberries & floral petals, scale spring centerpiece cake, and subtle gold dust atmosphere.
- **Signature Cakes Catalog:** Showcase featuring *Strawberry Dream*, *Velvet Romance*, *Chocolate Indulgence*, *Golden Vanilla*, *Rose & Pistachio Reverie*, and *Caramel Hazelnut Opera*.
- **Interactive Moments Showcase:** Dynamic categories (*Birthday Magic*, *Wedding Elegance*, and *Everyday Indulgence*) with smooth crossfade animations and feature breakdowns.
- **Brand Story & Heritage:** Editorial split-layout featuring master patissier craftsmanship, zero artificial fillers, and small-batch philosophy.
- **Ingredients & Craftsmanship:** Circular floating cards highlighting Alpine Berries, Belgian Couverture, Madagascar Bourbon Vanilla, and Farm Cream.
- **Testimonials Slider:** 5-star verified customer feedback with auto-play, manual slide controls, and pause-on-hover.
- **Social Photo Atelier:** Asymmetrical 6-photo masonry grid with Instagram hover details and high-resolution Lightbox view.
- **Frequently Asked Confections (FAQ):** Smooth gold-accented accordion addressing notice times, eggless/dietary choices, refrigerated delivery, and cake care.
- **Bespoke Order Flow:** Direct phone call (`+91 98765 43210`) and pre-filled WhatsApp concierge order links.
- **Fully Responsive:** Tested across mobile, tablet, laptop, and ultra-wide screens with zero horizontal overflow.

## 🚀 Getting Started

### 1. Clone & Install

```bash
git clone https://github.com/skavotechnologies-glitch/cakeshop.git
cd cakeshop
npm install
```

### 2. Run Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production

```bash
npm run build
npm run preview
```
